# MIDI inspection and bounded import

Inspect a local Standard MIDI File without rendering it:

```bash
sonumio music-midi-inspect input.mid
```

The reader accepts bounded format 0 and 1 PPQ files, running status,
physical note-on/off lifetimes, channel programs, tempo and signature
meta messages. It rejects malformed data, unclosed or ambiguous
same-channel notes, SMPTE timing, unsupported system status, overlong
variable-length quantities and resource-limit violations. Inspection
reports unapplied performance events and SysEx counts; it does not
interpret sustain, pitch bends, program changes across tracks or other
performance semantics.

Import uses an existing validated Sonumio score as a template:

```bash
sonumio music-midi-import input.mid --template score.json --output imported.json
```

The template supplies sections, harmony, tempo, duration, swing and
tonality. Automatic mapping is restricted to the Sonumio exporter
track names, channels and programs. For external files, supply
`--mapping mapping.json` with explicit note-bearing track/channel
mappings, optional expected program and pan:

```json
{"format":"sonumio-midi-import-v1","max_tick_error":0,
 "mappings":[{"track":0,"channel":0,"target":"lead","pan":0.18}]}
```

Mappings must be unique, sorted by source track and channel, and cover
every note-bearing pair. MIDI tick error tolerance is measured in
source PPQ ticks (0–16); zero is exact and the conversion uses integer
rational arithmetic. The importer rejects tempo changes, different
duration/meter, performance controllers, unsupported port routing,
SysEx, non-grid notes beyond the selected tolerance, and notes that
violate the resulting arrangement's scale or polyphony.

MIDI stores seven-bit velocity and the importer explicitly assigns pan.
It does not recover original six-decimal velocity, exact panning,
harmony or sections from a MIDI file. The resulting JSON can be rendered
with existing Sonumio tools; no audio is generated by import itself.
The CLI supports expected input/template/output SHA-256 pins and
atomic no-clobber output. Local file paths are trusted-user inputs.
