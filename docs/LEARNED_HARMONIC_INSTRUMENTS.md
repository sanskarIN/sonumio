# Learned harmonic instrument reconstruction experiment

This isolated experiment trains a small conditioned network to reconstruct
Sonumio's own five pitched procedural instruments. It predicts parameters
of a differentiable additive oscillator bank rather than next-note tokens.
It has no recorded instrument samples, external training data, pretrained
weights, text conditioning or claim of realistic instrument generation.

## Reproduce locally

```bash
python -m pip install -e '.[test,research]'
python -m pytest -q tests/test_instrument_harmonic_research.py
python -m research.instrument_harmonic_study --model-seeds 17,29,41 --updates 96
```

The study uses CPU float32 tensors. Nothing is saved except the numerical
JSON report printed to standard output; there is no model or WAV export.

## Source data and evaluation

The grid contains keys, pad, bass, lead and pluck, four training MIDI
pitches (48, 60, 72, 84), three velocities (0.3, 0.7, 0.95) and two note
lengths (4096, 8192 frames at 24 kHz). The complete training grid has 120
notes. Four separate held-out panels compare:

- pitches 54, 66, 78 with training velocities and lengths;
- velocities 0.5 and 0.85 with training pitches and lengths;
- duration 6144 frames with training pitches and velocities;
- all three held-out axes jointly.

The evaluation grid has 260 notes. Every source is generated by the
unchanged original instrument renderer. The corpus checks explicit note
identity and exact float32 waveform SHA256 separation across training and
evaluation, with independent panel fingerprints. This is interpolation
within a synthetic family, not a novel recording or artist-disjoint split.

## Neural synthesis

An instrument embedding and numeric note controls feed a small MLP. It
predicts time-varying nonnegative partial envelopes at sixteen anchors,
two banks of eight harmonic oscillators, bounded detuning, inharmonicity
and vibrato, and smooth attack/release fractions. The silent softmax
channel allows attenuation, and the sum of sounding amplitudes cannot
exceed one. The oscillator frequencies use a conservative Nyquist guard;
bounded modulation is not proof of strict alias-free synthesis.

The training objective is target-energy-normalized waveform MSE plus
0.25 times relative compressed-magnitude STFT error (256 and 1024 FFT
sizes). Phase-sensitive reconstruction can penalize perceptually similar
waves; the spectral term is likewise an objective diagnostic, not a
listening-quality measure.

## Prespecified controls and limitations

Three independently initialized networks receive the same training
samples and length-cycling minibatch schedule. The fixed optimizer budget
is 96 AdamW steps, with gradient norm clipping. There is no validation
selection or early stopping. Each seed compares matched trained predictions
to its own untrained predictions, a shared generic sine baseline and all
four wrong instrument labels with pitch, velocity, duration and target held
constant. Metrics are aggregated by instrument, then equally across the
five instruments. The report includes per-seed paired error differences,
their observed spread, numerical peak and RMS/correlation diagnostics,
model-state digests, and actual optimizer update/sample counts.

Positive error differences favor trained/matched reconstruction. No
improvement is assumed until the real run has been inspected. A model can
improve one metric while worsening another. Three initialization seeds
are not a statistical significance test. The same-runtime deterministic
data and model hashes are not guaranteed across CPU architectures and
library versions.

This is a source-only research module, not Sonumio-1, a release-ready
instrument synthesizer or an end-to-end text-to-music system. Existing
instrument rendering and learned symbolic music experiments remain
unchanged. Future work requires stronger signal models, longer notes,
independent permitted audio sources, listening evaluation and an explicit
decision about model integration and weight publication.
