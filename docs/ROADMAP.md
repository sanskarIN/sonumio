# Sonumio roadmap (planning; not publication approval)

- **v0.1.0 development**: local DSP WAV generator, CLI, FastAPI, provenance registry, validation, tests. Working in prototype; MusicGen GPU inference unverified.
- **v0.2.0 planned**: accessible React + TypeScript web frontend, waveform player, bounded async jobs, lifecycle cleanup, quota and auth architecture, stronger model regression tests.
- **v0.3.0 planned**: task-aware model routing, appropriately licensed local text-to-audio integrations, evaluation harness, Hindi-language tests, model version/weight integrity registry.
- **Research toward Sonumio-1**: license-reviewed dataset metadata, tiny trained conditional spectral baseline, model ablations, repeatable checkpoints and independent evaluation.
- **v1.0.0 eventual stable gate**: measurable audio quality, security, reproducibility, model provenance and broad platform QA requirements satisfied.

No GitHub release, pre-release or weights will be published without explicit approval.
